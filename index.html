01 — AI Agent / Computer Vision / Productivity Automation

CV Agent

Telegram BotQwen2.5-VLVisual ReasoningGroq APISQLiteFlask

CV Agent is a Telegram-based AI productivity and computer vision assistant designed to manage daily tasks, reminders, important dates, emails and visual note scanning from one chat interface.

The system uses Qwen2.5-VL for visual reasoning on uploaded images, supporting note scanning, reminder extraction and follow-up image analysis.

It also uses Groq-powered AI chat for natural-language responses, SQLite storage for tracked information, Gmail IMAP email triage, and a Flask dashboard for viewing reminders, notes, university application tracking, AI summaries and scheduled briefings.

03 — IoT / Sensor Systems / AWS Integration

People Counter App — Smart IR Detection System

IoTAWSESP8266IR Sensors

People Counter App is a final year IoT project focused on real-time people counting using ESP8266 microcontrollers and infrared sensors.

The system monitors entry and exit using directional IR beam detection to reduce false triggers, while a centralised Master Hub coordinates sensor nodes over WiFi.

Live data is displayed through a web dashboard and Flutter-based mobile application, with IoT data also connected to AWS for cloud-based transmission, storage and monitoring.

TypeFinal Year IoT Project
FocusDirectional detection, real-time counting, sensor validation and cloud-connected data
Tools UsedESP8266, IR Sensors, WiFi Hub, Flutter App, Web Dashboard, AWS
OutcomeReliable people-counting workflow with live monitoring and cloud integration
